# P4 决策

## 为什么另开仓库

工单分流的知识库是关键词匹配，评测门禁已经对准那套工具。向量检索放在本仓库，避免改动工单项目的引用规则。

## 这一版的检索

句子嵌入用 `paraphrase-multilingual-MiniLM-L12-v2`（ONNX，经 fastembed 加载）。权重放在 `.data/models`，不进 git。没有 API Key。向量会归一化，相似度是余弦。

入库时把标题和正文一起编码，引用摘录仍只含正文。

回答是摘录，不是自由生成。每条引用的 `excerpt` 必须等于命中的原文。

门槛是 0.50。另外只保留与最高分相差不超过 0.05 的块，避免「几天内可以退款」顺手引用「7 天冷静期」。天气和闲聊的最高分大约 0.12，仍然零引用。

## 不做

- 生成式模型先写再补引用
- 把本仓库的索引写进工单分流的 SQLite
