# P4 决策

## 为什么另开仓库

工单分流的知识库是关键词匹配，评测门禁已经对准那套工具。向量检索放在本仓库，避免改动工单项目的引用规则。

## 这一版的检索

用确定性的哈希向量和余弦相似度，而不是下载句子嵌入模型。这样 `pytest` 和黄金集在没有 API Key、没有外网模型的环境里也能跑。

回答是摘录，不是自由生成。每条引用的 `excerpt` 必须等于命中的原文。

相似度门槛是 0.15。短问句「几天内可以退款」对退款政策大约 0.19，仍应命中；天气和闲聊是 0 或负数，不能带引用。

## 不做

- 生成式模型先写再补引用
- 把本仓库的索引写进工单分流的 SQLite
